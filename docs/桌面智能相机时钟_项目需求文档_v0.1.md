> 项目暂定名：**DeskCam Clock / 桌面智能相机时钟**  
> 文档版本：v0.1  
> 文档日期：2026-05-13  
> 目标硬件：立创开发板 ESP32-S3 实战派开发板 + TF/SD 卡 + 外接 WS2812 灯环/灯条  
> 当前阶段：需求定义与功能范围确认

## 1. 项目概述

### 1.1 项目定位

本项目是一款基于 ESP32-S3 实战派开发板的桌面智能小终端，核心定位为：

**平时是桌面时钟、天气屏、氛围灯和数码相框；需要互动时，可以拍照、播放音乐、管理 SD 卡文件，并通过手机或电脑网页进行控制。**

它不是单一功能的时钟、相机或音箱，而是一个集成多种桌面功能的小型智能摆件。

### 1.2 一句话描述

一台具备 **时钟、天气、拍照、相册、SD 卡文件管理、本地音乐、网络电台、WS2812 氛围灯、Web 控制台** 的桌面智能相机时钟。

### 1.3 核心价值

本项目希望实现以下体验：

1. **常驻有用**：放在桌面上可以持续显示时间、日期、天气和状态信息。
2. **随手记录**：可通过触摸或按键拍照，并将照片保存到 SD 卡。
3. **方便导出**：支持 USB U 盘模式和 Wi-Fi 网页方式管理照片。
4. **桌面氛围**：可播放本地音乐、网络电台，并通过屏幕和 WS2812 灯效营造氛围。
5. **可扩展**：后期可以加入电子宠物、语音备忘录、番茄钟、白噪声等桌面功能。
6. **偏产品化**：不是单个 Demo，而是具备首页、菜单、设置、文件管理、Web 控制台和版本迭代路线的完整小项目。

## 2. 项目边界

### 2.1 本项目第一阶段要做什么

第一阶段重点做成一个可长期摆在桌面的可用设备：

- 桌面时钟首页
- 天气显示
- Wi-Fi 配网与网络校时
- 小相机预览与拍照
- 照片保存到 SD 卡
- 设备端相册浏览
- Wi-Fi 网页相册
- 基础 Web 控制台
- WS2812 基础灯效
- 基础系统设置
- 类似于手机的下划进入状态栏，调剂亮度、声音等功能

### 2.2 本项目后续阶段要做什么

后续逐步增加：

- USB U 盘模式导出照片
- SD 卡本地音乐播放器
- Wi-Fi 网络电台
- 手机网页上传音乐 / 投喂电台 URL
- 数码相框自动轮播
- 更多灯效和音乐律动
- 拍照滤镜、拍立得边框、天气水印
- 桌面电子宠物
- 语音备忘录
- 番茄钟 + 白噪声专注器
- OTA 固件升级
- 电脑状态小屏

### 2.3 第一阶段明确不做

为了控制复杂度，第一阶段不做：

1. 不做传统蓝牙 A2DP 音箱。
2. 不做视频录像。
3. 不做复杂 AI 识别。
4. 不做手机 App。
5. 不做公网远程访问。
6. 不做电池供电管理。
7. 不做复杂多任务高负载并行，例如拍照预览、网络电台、USB U 盘访问 SD 卡同时运行。
8. 不做云端账号体系。
9. 不做批量 ZIP 下载照片。
10. 不做复杂插件市场。

## 3. 硬件基础与约束

### 3.1 目标硬件资源

项目基于 ESP32-S3 实战派开发板，预计会使用以下硬件能力：

| 硬件资源 | 用途 |
|---|---|
| ESP32-S3 主控 | 主程序、Wi-Fi、UI、文件管理、音频控制 |
| 2.0 寸 IPS 屏 | 时钟、天气、相机预览、相册、音乐界面、设置界面 |
| 电容触摸 | 页面切换、拍照、确认、设置操作 |
| GC0308 摄像头 | 小相机拍照、预览、延时摄影扩展 |
| TF/SD 卡 | 存储照片、音乐、配置、主题资源、日志 |
| 音频输入输出链路 | 音乐播放、提示音、后期录音 |
| 喇叭 | 音乐、网络电台、按键音、闹钟、提示音 |
| Wi-Fi | 天气、时间同步、网页控制台、网络电台 |
| Bluetooth LE | 后期可用于 BLE 配网或简单遥控，不作为传统蓝牙音频通道 |
| USB | 后期作为 USB U 盘模式、调试串口、可能的复合设备 |
| 外拓 IO | 接 WS2812、按键、传感器、状态灯等 |
| QMI8658 姿态传感器 | 后期电子宠物、姿态交互、拿起唤醒等 |

### 3.2 关键硬件约束

#### 3.2.1 摄像头约束

GC0308 摄像头更适合做低分辨率小相机、复古相机、桌面记录、延时拍照，不适合做高清摄影或高质量视频。

因此本项目相机定位为：

- 玩具相机
- 桌面拍照记录器
- 复古拍立得风格相机
- 小型延时摄影工具

不建议把它定位为高清相机或视频记录仪。

#### 3.2.2 蓝牙音频约束

ESP32-S3 支持 Bluetooth LE，但不适合作为传统经典蓝牙 A2DP 音箱。

因此本项目音乐方向定为：

- SD 卡本地音乐播放器
- Wi-Fi 网络电台
- 手机通过网页上传音乐
- 手机通过网页投喂音频流 URL
- 后期可研究 USB Audio 或外接经典蓝牙音频模块

第一阶段不把“手机蓝牙直连播放音乐”作为需求。

#### 3.2.3 SD 卡访问约束

SD 卡同时承担照片、音乐、配置和主题资源存储，因此必须限制并发访问。

基本规则：

- 拍照保存时，避免同时进行大规模网页文件操作。
- USB U 盘模式下，设备端应暂停访问 SD 卡。
- 播放音乐时，不建议同时生成大量照片缩略图。
- Web 上传文件时，需检查剩余空间并避免文件名冲突。
- 配置文件写入应采用临时文件 + 原子替换策略，降低断电损坏风险。

#### 3.2.4 WS2812 供电约束

WS2812 灯珠数量较多时电流会明显增加。

建议：

- 8~16 颗灯珠适合作为第一版。
- 超过 16 颗建议使用独立 5V 供电。
- 外部 5V 电源与开发板需要共地。
- 软件中限制最大亮度，避免启动瞬间电流过大。
- 默认亮度不超过 40%。
- 夜间模式亮度建议 5%~15%。

## 4. 用户场景

### 4.1 日常桌面时钟

用户将设备放在桌面，平时显示时间、日期、天气和状态。夜间自动降低亮度，不刺眼。

典型流程：

1. 设备上电。
2. 自动连接 Wi-Fi。
3. 自动校时。
4. 拉取天气。
5. 显示桌面时钟首页。
6. 夜间自动进入低亮度模式。

### 4.2 随手拍照

用户看到桌面上有趣的东西或想记录瞬间，可快速拍照。

典型流程：

1. 用户短按实体键或从首页滑到相机。
2. 屏幕进入相机预览。
3. 用户按键或触摸快门。
4. 设备播放快门音效并闪屏。
5. 照片保存到 SD 卡。
6. 屏幕显示拍摄结果。
7. 用户可进入相册查看。

### 4.3 手机查看照片

用户不拔 SD 卡，直接用手机浏览器下载照片。

典型流程：

1. 设备与手机处于同一 Wi-Fi。
2. 设备屏幕或设置页显示访问地址。
3. 用户在手机浏览器打开 Web 控制台。
4. 进入相册页面。
5. 查看照片缩略图。
6. 点击单张照片预览或下载。

### 4.4 电脑导出照片

用户希望一次性整理照片，可以连接电脑进入 USB U 盘模式。

典型流程：

1. 用户用 USB 线连接设备和电脑。
2. 在设备设置中选择“USB 文件传输模式”。
3. 设备暂停相机、相册、音乐和 Web 文件写入。
4. 电脑识别为 U 盘。
5. 用户复制照片。
6. 用户在电脑端安全弹出。
7. 用户在设备端退出 U 盘模式。
8. 设备重新挂载 SD 卡并回到首页。

### 4.5 桌面音乐氛围

用户工作或休息时播放本地音乐或网络电台，同时开启灯效。

典型流程：

1. 用户进入音乐页面。
2. 选择 SD 卡音乐或网络电台。
3. 设备播放音乐。
4. 屏幕显示歌名、进度、音量。
5. WS2812 根据音乐或模式显示灯效。
6. 用户通过触摸或网页调节音量和灯效。

### 4.6 数码相框

用户让设备自动轮播 SD 卡中的照片，作为桌面小相框。

典型流程：

1. 用户进入相册页面。
2. 选择“自动轮播”。
3. 选择今日照片、全部照片或收藏照片。
4. 设置轮播间隔。
5. 设备自动展示照片。
6. 可叠加时间、日期和天气信息。

## 6. 功能需求详述

## 6.1 桌面时钟首页

### 6.1.1 功能目标

桌面时钟首页是设备默认界面，也是用户最常看到的界面。

它需要做到：

- 信息清晰
- 长时间显示不杂乱
- 低亮度下可读
- 可通过主题变换风格
- 可以快速进入相机、音乐、相册和设置

### 6.1.2 显示内容

| 内容 | 优先级 | 说明 |
|---|---|---|
| 当前时间 | P0 | 大字号显示，支持 24 小时制 |
| 日期 | P0 | 显示年月日 |
| 星期 | P0 | 显示周一至周日 |
| 天气图标 | P0 | 晴、多云、雨、雪等 |
| 当前温度 | P0 | 显示当前温度 |
| 城市 | P1 | 当前天气城市 |
| Wi-Fi 状态 | P0 | 已连接/未连接 |
| SD 卡状态 | P0 | 已挂载/未挂载/异常 |
| 音乐状态 | P1 | 播放中/暂停 |
| 灯光状态 | P1 | 当前灯效 |
| 电源状态 | P2 | 后期加入电池后显示 |
| 闹钟/提醒 | P2 | 后期拓展 |

### 6.1.3 表盘主题

第一阶段建议实现 3 套主题：

| 主题名称 | 风格 | 主要显示 |
|---|---|---|
| 极简数字钟 | 简洁、实用 | 时间、日期、天气 |
| 像素天气钟 | 可爱、桌面摆件感 | 像素天气图标、时间 |
| 科技仪表盘 | 信息密度高 | 时间、状态栏、天气、图标 |

后期可支持从 SD 卡加载主题资源：

```text
/THEMES/
  minimal/
    theme.json
    bg.png
    icons/
  pixel_weather/
    theme.json
    bg.png
    icons/
```

### 6.1.4 首页交互

| 操作 | 功能 |
|---|---|
| 左右滑动 | 切换主功能页面 |
| 上下滑动 | 调节亮度或音量 |
| 单击屏幕 | 显示快捷菜单 |
| 长按屏幕 | 进入设置 |
| 短按实体键 | 快速进入相机或拍照 |
| 双击实体键 | 切换相册 / 时钟 |
| 长按实体键 | 熄屏 / 唤醒 |

### 6.1.5 首页状态栏

建议底部或顶部显示简化状态栏：

```text
Wi-Fi | SD | Music | Lamp | 14:32
```

图标状态：

| 图标 | 状态 |
|---|---|
| Wi-Fi | 已连接、断开、配网中 |
| SD | 正常、未插入、错误、空间不足 |
| Music | 播放、暂停、静音 |
| Lamp | 开启、关闭、自动模式 |
| USB | 普通模式、U 盘模式 |
| Web | Web 控制台已启用 |

### 6.1.6 验收标准

- 设备上电后能进入首页。
- 联网成功后能自动校时。
- 首页时间显示误差在网络校时后应小于 5 秒。
- 天气信息能成功刷新并显示。
- Wi-Fi 断开时首页能明确提示。
- SD 卡未插入时首页能明确提示。
- 用户可从首页进入相机、相册、音乐、灯光和设置。

## 6.2 小相机模式

### 6.2.1 功能目标

小相机模式用于实现快速拍照、复古记录和桌面照片采集。

核心体验：

- 进入相机后显示实时预览。
- 可按键或触摸拍照。
- 拍照后保存到 SD 卡。
- 拍完可立即查看。
- 支持后续滤镜和拍立得风格。

### 6.2.2 基础拍照流程

```text
进入相机
  ↓
初始化摄像头
  ↓
屏幕显示预览
  ↓
用户按键/触摸快门
  ↓
执行拍照
  ↓
保存到 SD 卡
  ↓
显示拍摄结果
  ↓
返回预览或进入相册
```

### 6.2.3 拍照功能列表

| 功能 | 优先级 | 说明 |
|---|---|---|
| 实时预览 | P0 | 屏幕显示摄像头画面 |
| 按键拍照 | P0 | 物理按键作为快门 |
| 触摸拍照 | P0 | 屏幕按钮作为快门 |
| 拍照保存 | P0 | 保存到 SD 卡 |
| 拍完预览 | P0 | 显示刚拍的照片 |
| 拍照音效 | P1 | 喇叭播放快门音 |
| 拍照闪屏动画 | P1 | 增强反馈 |
| 倒计时拍照 | P1 | 3 秒 / 5 秒 |
| 滤镜拍照 | P1 | 黑白、暖色、像素 |
| 连拍模式 | P2 | 一次拍多张 |
| 定时拍照 | P2 | 每隔固定时间拍照 |
| 延时摄影 | P2 | 长期记录并按日期存储 |
| 画面变化自动拍照 | P3 | 后期扩展 |

### 6.2.4 照片格式与命名

建议命名规则：

```text
IMG_YYYYMMDD_HHMMSS.jpg
```

示例：

```text
IMG_20260513_143205.jpg
```

建议目录：

```text
/DCIM/
  /2026-05-13/
    IMG_20260513_143205.jpg
    IMG_20260513_143312.jpg
```

### 6.2.5 拍照滤镜

建议滤镜分阶段实现：

| 滤镜 | 优先级 | 效果 |
|---|---|---|
| 原图 | P0 | 默认 |
| 黑白 | P1 | 复古感 |
| 暖色 | P1 | 拍立得感 |
| 冷色 | P2 | 科技感 |
| 像素化 | P2 | 玩具相机感 |
| 时间水印 | P2 | 叠加日期时间 |
| 天气水印 | P2 | 叠加天气和温度 |
| 拍立得边框 | P2 | 白边 + 日期 |

### 6.2.6 异常处理

| 异常 | 处理方式 |
|---|---|
| SD 卡未插入 | 禁止拍照保存，提示“未检测到 SD 卡” |
| SD 卡空间不足 | 提示“空间不足”，禁止拍照 |
| 摄像头初始化失败 | 提示“摄像头错误”，允许返回首页 |
| 保存失败 | 提示失败原因，保留预览 |
| 文件名冲突 | 自动递增序号或使用时间戳 |
| 拍照过程中进入 USB U 盘模式 | 禁止进入，提示需先退出相机 |

### 6.2.7 验收标准

- 相机模式可稳定进入和退出。

## 6.3 SD 卡照片管理

SD 卡照片管理包含两个主要通道：

1. USB U 盘模式
2. Wi-Fi 网页模式

---

### 6.3.1 USB U 盘模式

#### 功能目标

设备连接电脑后，可切换为 U 盘模式，让电脑直接访问 SD 卡照片。

#### 模式规则

USB U 盘模式是独占模式。

进入该模式后：

- 停止相机预览。
- 停止拍照保存。
- 停止音乐播放。
- 停止设备端相册访问。
- 暂停 Web 文件上传、删除等写入操作。
- 电脑独占访问 SD 卡。
- 屏幕显示文件传输状态。

#### 用户流程

```text
设备连接电脑
  ↓
用户进入 设置 → 文件管理 → USB U 盘模式
  ↓
设备提示“进入后将暂停拍照/音乐”
  ↓
用户确认
  ↓
设备卸载内部 SD 卡访问
  ↓
启动 USB MSC
  ↓
电脑识别 U 盘
  ↓
用户复制文件
  ↓
电脑安全弹出
  ↓
用户点击设备端“退出 U 盘模式”
  ↓
设备重新挂载 SD 卡
  ↓
返回首页
```

#### 界面提示

进入 U 盘模式后屏幕显示：

```text
USB 文件传输中

请在电脑上安全弹出后
再点击退出

当前模式下：
拍照、相册、音乐已暂停
```

#### 功能列表

| 功能 | 优先级 | 说明 |
|---|---|---|
| 手动进入 U 盘模式 | P1 | 从设置页进入 |
| 电脑识别 SD 卡 | P1 | 作为 U 盘访问 |
| 设备端暂停 SD 访问 | P1 | 避免文件系统冲突 |
| 退出后重新挂载 SD 卡 | P1 | 恢复正常模式 |
| 安全弹出提醒 | P1 | 提醒用户先弹出 |
| USB 复合设备 | P3 | 串口 + U 盘等后期功能 |

#### 验收标准

- 电脑能识别设备为 U 盘。
- 能在电脑端读取照片目录。
- U 盘模式期间设备端不写入 SD 卡。
- 退出 U 盘模式后设备能重新读取照片。
- 非正常拔出时，设备应能提示并尝试重新挂载。

可以利用二维码来实现扫码进入web

## 6.5 WS2812 小台灯 / 氛围灯

### 6.5.1 功能目标

外接 WS2812 灯环或灯条，让设备具备桌面小台灯和氛围灯能力。

灯效可与以下场景联动：

- 天气
- 音乐
- 拍照倒计时
- 通知
- 夜间模式
- 系统错误提示
- 专注模式

### 6.5.2 灯光基础参数

| 参数 | 说明 |
|---|---|
| 灯珠类型 | WS2812 / WS2812B |
| 推荐数量 | 8~16 颗 |
| 数据引脚 | 使用外拓 IO |
| 供电 | 少量灯珠可从板上取电，较多灯珠建议独立 5V |
| 最大亮度 | 软件限制，默认不超过 40% |
| 夜间亮度 | 5%~15% |
| 默认模式 | 呼吸灯或天气灯效 |

### 6.5.3 灯效模式

| 灯效 | 优先级 | 说明 |
|---|---|---|
| 关闭 | P0 | 关闭所有灯 |
| 纯色灯 | P0 | 指定颜色 |
| 亮度调节 | P0 | 0~100%，软件限制最大实际亮度 |
| 呼吸灯 | P0 | 柔和明暗变化 |
| 彩虹流动 | P1 | 氛围灯 |
| 天气灯效 | P1 | 根据天气变化 |
| 拍照倒计时 | P1 | 拍照前 3、2、1 灯光反馈 |
| 通知闪烁 | P1 | 错误、提醒、消息 |
| 夜灯模式 | P1 | 低亮暖光 |
| 音乐律动 | P2 | 跟随音乐音量变化 |
| 自定义灯效 | P3 | Web 端配置 |

### 6.5.4 天气灯效规则

| 天气 | 灯效 |
|---|---|
| 晴天 | 暖色柔光 |
| 多云 | 白蓝渐变 |
| 雨天 | 蓝色流动 |
| 雪天 | 冷白闪烁 |
| 雷雨 | 偶发闪光 |
| 雾霾 | 低饱和灰黄色 |
| 夜间 | 低亮度暖光 |

### 6.5.5 音乐律动规则

第一版音乐律动不做复杂 FFT，可先基于音量能量实现。

| 音量强度 | 灯效 |
|---|---|
| 低 | 微弱呼吸 |
| 中 | 慢速跳动 |
| 高 | 快速闪动 |
| 静音 | 柔光或熄灭 |

后期可扩展：

- 频谱柱状灯效
- 节拍检测
- 多色音浪
- 与屏幕频谱同步

### 6.5.6 控制方式

| 控制方式 | 功能 |
|---|---|
| 设备触摸屏 | 开关、模式、亮度 |
| 实体按键 | 快速开关灯 |
| Web 控制台 | 颜色、亮度、模式、场景 |
| 自动联动 | 天气、音乐、拍照、夜间 |

### 6.5.7 验收标准

- WS2812 能正常点亮。
- 支持开关、亮度、纯色、呼吸灯。
- Web 端可控制灯效。
- 夜间模式能自动降低亮度。
- 拍照倒计时灯效能与相机联动。
- 灯效运行不应明显影响时钟刷新和基础交互。

### 6.8.3 配置写入策略

为了降低断电导致配置损坏的概率：

1. 写入 `config.tmp`。
2. 校验 JSON 格式。
3. 删除旧 `config.bak`。
4. 将当前 `config.json` 重命名为 `config.bak`。
5. 将 `config.tmp` 重命名为 `config.json`。
6. 写入失败时尝试恢复 `config.bak`。

### 6.8.4 验收标准

- 恢复默认设置后设备可重新配网。
- 设置页面能显示 SD 卡、Wi-Fi、固件等状态。

## 12. 非功能需求

### 12.1 稳定性

- 设备应支持长时间运行。
- 首页时钟不可频繁卡死。
- Wi-Fi 断开后应能自动重连。
- SD 卡异常不应导致系统崩溃。
- Web 访问失败不影响设备端基本功能。
- 音乐播放失败应能返回音乐页面。

### 12.2 性能

| 项目 | 建议目标 |
|---|---|
| 首页刷新 | 时间每秒更新 |
| 页面切换 | 1 秒内完成 |
| 拍照保存 | 尽量 3 秒内完成 |
| Web 状态 API | 1 秒内返回 |
| 相册列表加载 | 首屏 2 秒内显示 |
| 音乐播放响应 | 点击后 2 秒内开始或提示缓冲 |
| 灯效刷新 | 肉眼连续，无明显卡顿 |

### 12.3 可维护性

- 模块化代码结构。
- 所有配置集中管理。
- 文件路径统一定义。
- 错误码和日志统一。
- Web API 版本化。
- UI 页面与业务逻辑尽量分离。

### 12.4 安全性

- Web 控制台默认仅局域网可访问。
- 设置页支持管理密码。
- 删除、恢复出厂、重启等操作需要确认。
- 文件上传限制类型和路径。
- 不保存明文 Wi-Fi 密码到可直接下载的文件中。
- 不支持公网远程访问。

### 12.5 易用性

- 上电后自动进入首页。
- 未配网时自动提示配网。
- 屏幕显示 Web 访问地址。
- 关键错误用图标和文字提示。
- SD 卡目录规则清晰，电脑打开也能理解。
- 第一版无需手机 App。

## 16. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 功能过多导致开发周期过长 | 项目难以完成 | 分 V1/V2/V3 迭代 |
| SD 卡并发访问损坏文件系统 | 照片/音乐丢失 | 设计模式互斥和文件锁 |
| 摄像头画质有限 | 用户预期落差 | 定位为复古玩具相机 |
| ESP32-S3 不支持经典蓝牙音箱 | 音频需求受限 | 改为 SD 音乐 + Wi-Fi 电台 |
| 网络电台格式复杂 | 播放失败 | 只支持明确格式的 MP3/HTTP 流 |
| Web 控制台占用资源 | UI 卡顿 | 限制并发连接和大文件操作 |
| WS2812 电流过大 | 供电不稳 | 限亮度、外部供电 |
| 界面过复杂 | 2 寸屏难操作 | 设备端简化，复杂功能放 Web |
| 配置文件损坏 | 无法启动 | 默认配置 + 备份恢复 |
| 长时间运行内存泄漏 | 系统不稳定 | 模块化测试、日志监控 |

## 17. 待确认需求清单

下一步需要确认以下具体需求：

### 17.1 外观与交互

- 是否需要设计外壳？
- WS2812 是灯环、灯条还是底座？
- 是否使用额外实体按键？
- 快门键是否独立？
- 是否需要旋钮调音量/亮度？

### 17.2 网络与天气

- 天气接口选择哪个服务？
- 城市是手动设置还是通过 IP 粗略定位？
- 天气刷新频率是多少？
- 是否需要显示未来天气？

### 17.3 相机

- 第一版是否只保存原图？
- 是否需要拍照倒计时？
- 是否需要时间水印？
- 照片是否需要缩略图？

### 17.4 音乐

- 第一版音乐是否推迟到 V2？
- 是否只支持 MP3/WAV？
- 是否需要物理音量键？
- 网络电台是否只支持预设列表？

### 17.5 Web 控制台

- 是否需要登录密码？
- 是否允许上传音乐？
- 是否允许删除照片？
- 是否需要 OTA？
- 是否需要移动端优先页面？

### 17.6 存储

- SD 卡推荐容量是多少？
- 是否限制单个音乐文件大小？
- 是否需要日志保留天数？
- 是否需要一键清理旧照片？

## 18. 推荐的最终 V1 需求冻结版本

建议 V1 冻结为以下功能：

1. 桌面时钟首页  
   - 时间、日期、星期、天气、状态栏。
2. Wi-Fi 和时间  
   - SoftAP 配网、连接 Wi-Fi、SNTP 校时。
3. SD 卡  
   - FAT32 挂载、目录初始化、容量检测。
4. 小相机  
   - 实时预览、按键拍照、触摸拍照、保存照片。
5. 相册  
   - 设备端浏览照片、上一张、下一张。
6. Web 控制台  
   - 状态页面、相册列表、单张预览、单张下载、基础设置。
7. WS2812 灯  
   - 开关、亮度、纯色、呼吸灯。
8. 设置  
   - 城市、亮度、音量、主题、设备信息。
9. 异常处理  
   - Wi-Fi 失败、SD 卡异常、摄像头错误、空间不足提示。

V1 暂不包含：

- USB U 盘模式
- 音乐播放
- 网络电台
- 手机上传音乐
- 数码相框自动轮播
- 电子宠物
- 语音备忘录
- 番茄钟
- OTA

这样 V1 更容易完成，也能验证项目核心体验。

## 20. 结论

本项目建议以 **“桌面智能相机时钟”** 作为产品定位。

它的核心不是单独把某个功能做到极致，而是把以下能力整合成一个稳定、好玩、可长期摆桌面的设备：

- 时钟
- 天气
- 拍照
- 相册
- SD 卡管理
- Web 控制台
- 音乐
- 网络电台
- WS2812 小台灯
- 数码相框
- 后期桌面宠物和专注工具

最推荐的实现路线是：

```text
V1：时钟 + 天气 + 拍照 + SD 卡 + Web 相册 + 基础灯光
V2：USB U 盘 + 音乐播放器 + 网络电台 + 数码相框
V3：滤镜 + 音乐律动灯 + 手机投喂音乐 + 电子宠物雏形
V4：语音备忘录 + 番茄钟 + 白噪声 + OTA + 电脑状态小屏
```

通过这种阶段式开发，可以先快速做出一个能用的桌面小设备，再逐步增强氛围感、交互感和产品完整度。
